# 🪔 Nightingale Beacon Suite

**Change lives. Beginning with your own.**

A free, open collection of **18 single-file, browser-based learning games** plus a
walkable campus hub — built for nursing and general-education students at
**Nightingale College**. Every game is one self-contained HTML file: no installs,
no accounts, no tracking. Open it and play.

> 🎮 **[▶ Enter the Campus Hub](02_hub/index.html)** &nbsp;·&nbsp;
> 🗺️ **[Explore the Overworld Map](02_hub/beacon_general_overworld.html)**

## What's inside

| Area | Games |
|---|---|
| **Biology / Health** | Anatomy · Physiology · Pathophysiology · Microbiology · Nutrition |
| **Math** | Algebra · Statistics |
| **English** | Composition · Editor's Desk |
| **Communication** | SpeechCraft |
| **Psychology** | Psychology · Psych Lab · Lifespan |
| **Sociology** | Society · Culture |
| **Humanities** | Western Civilization · Ethics |

Each title features NCLEX-style practice questions with rationales, boss
encounters, collectible cards, achievements, an accessible "Choose Your Narrator"
voice option, and works fully offline.

Plus a set of **SCI 225 Pathophysiology study guides and flashcards** in
[`/guides`](guides/) — color-coded, exam-focused, and print-to-PDF ready.

---

## How to use

- **Students:** open the [Campus Hub](02_hub/index.html) and pick a course, or
  walk the [Overworld Map](02_hub/beacon_general_overworld.html).
- **Instructors:** every file is standalone — link any single game directly, or
  host the whole folder. Nothing phones home.
- **On your phone:** tablet D-pad controls are built in; desktop uses arrow keys / WASD.
